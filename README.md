## Who I am

Full-stack developer and SDE I at **LinktoDM** — building and shipping features in a real production codebase while concurrently finishing my B.Tech in Information Technology.

On the frontend I work with **Svelte + TypeScript**, writing components, managing state, and keeping interfaces fast and clean. On the backend I build REST APIs with **Python + FastAPI** backed by **PostgreSQL**, handling data modelling, query optimisation, and auth flows.

Everything I build is built with actual users and production constraints in mind — not just assignments.
